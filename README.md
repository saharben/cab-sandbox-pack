# CAB sandbox pack

Optional guest-only runtimes and the Qwen3 0.6B model for the Pi and Ollama integrations in Creators & Advisors Board.

Install the compatible generation through **CAB Preferences → Sandbox**. CAB verifies the exact approved bytes and applies the existing local sandbox and file access checks.

[Pack v1 downloads](https://github.com/saharben/cab-sandbox-pack/releases/tag/pack-v1-d2b114e03ea8) include the four runtime/model files, their manifest, and the third-party notices and corresponding source. Component licenses are described in the download's provenance file.\n
